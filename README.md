# مبيعات الجنوبية — النسخة الجديدة

Expo SDK 54 + Supabase. المشروع مربوط بقاعدة `Target Sales New` عبر متغيرات البيئة فقط.

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. ضع `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` من Supabase.
3. نفّذ `npm install` ثم `npx expo start`.
4. عند بناء Android استخدم EAS/Expo مع package `com.targetsales.app`.

## ما تم ربطه
- تسجيل الدخول باسم المستخدم بعد تفعيل حساب Supabase Auth.
- منطقة واحدة: الجنوبية.
- شاشة موظف: التارجت، التوزيع، GPS، بداية/نهاية الشفت، الغياب، الباقات والمبيعات، الإشعارات.
- شاشة إدارة موحدة: 15 موظف، حالة الشفت، الموقع، الباقات، النقاط، اعتماد/رفض المبيعات.
- جميع النقاط والتارجت والحضور تُحسب من قاعدة البيانات وليس من التطبيق.
- ربط الجهاز يستخدم نفس بصمة الجهاز القديمة.

## ملاحظة التفعيل
بيانات الموظفين التاريخية موجودة بالكامل في `Target Sales New`. كلمات المرور القديمة لم تُنسخ بين المشروعين. يجب إنشاء مستخدمي Supabase Auth وربط `profiles.auth_user_id` قبل التشغيل الفعلي.
